# Omkar Kharade & Co. — CA Website

A responsive static website concept for **Omkar Kharade & Co., Chartered Accountants**, based on the supplied business card and inspired by the feature structure of the provided GMJ reference website.

## Included
- Responsive home, about, services, team, career and contact sections
- Services navigation
- Knowledge Bank with calculators, bulletins, utilities, acts/rules and forms
- Working GST, EMI, Net Profit and TDS calculators
- Contact enquiry form demo
- Mobile navigation
- Business-card logo crop in `assets/`

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Production checklist
- Connect the contact form to your email/CRM/WhatsApp backend.
- Replace placeholder knowledge-bank links with verified official resources.
- Add your final ICAI registration / membership details if required.
- Add Google Maps embed and social profiles if desired.
- Configure a domain, HTTPS, analytics and SEO metadata.
